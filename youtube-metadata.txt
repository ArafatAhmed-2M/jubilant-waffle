📝 The Universal Test Prompt (paste into any model):

"Build a single-file HTML page (no external libraries, no CDN) that is a fully working operating-system-style dashboard. It MUST contain ALL of these 8 sections in this order:

1. A live clock topbar — shows current time, updates every second, has a subtle glow.
2. A typewriter terminal — animates text character-by-character, then erases and repeats with a different boot log. Must include at least 8 boot lines.
3. A radar chart — uses pure JavaScript trigonometry (Math.sin / Math.cos). No chart libraries. Has at least 5 axis labels with values, and the polygon must animate from radius 0 to its full size.
4. A scrolling stats ticker — horizontal marquee of at least 6 stats that loops continuously.
5. Six feature cards — each with an icon (use SVG, not emoji), a title, a one-line description, and a subtle hover transform. Background should be slightly translucent so the page gradient shows through.
6. A quiz module — at least 3 multiple-choice questions. After answering, show correct/incorrect with a green or red flash. Score counter at the top.
7. A syntax-highlighted code block — show 30+ lines of real, runnable code (Python, JS, or similar) with proper token coloring (keywords, strings, comments all different colors). No library-based highlighting.
8. An animated footer — particles or shapes drifting upward, a copyright year that updates live.

Constraints:
- ONE single .html file, all CSS and JS inline. No external imports. No CDN links.
- Target: under 800 lines total. Be concise.
- Use CSS variables for the color theme. Make sure hex values are NOT wrapped in quotes inside var() definitions.
- Make the terminal a normal block in the document flow (not position:fixed) so it scrolls with the page.
- For the radar chart, divide each metric value by 100 before computing the polygon point, so the polygon fits inside the chart area.
- Self-check before finishing: confirm no CSS quote bugs, all 8 sections present, terminal not position:fixed, radar math divides by 100, no raw reasoning tags in the final HTML."
